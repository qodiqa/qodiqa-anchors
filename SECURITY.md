# Security policy

This repository holds only hashes, positions and public keys. A problem here is most likely a rewritten history, a statement that goes backwards, or a key that should not be listed.

Report privately: GitHub private vulnerability reporting (Security tab), or security@qodiqa.com. Please do not open a public issue. We acknowledge within 5 working days and ask for 90 days of coordinated disclosure; these are targets for a small team, not guarantees.
